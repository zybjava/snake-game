# 🐍 贪吃蛇小游戏

一个纯 HTML + CSS + JavaScript 实现的经典贪吃蛇游戏，单文件、零依赖，浏览器打开即玩！

## 🎮 在线试玩

把仓库开启 **GitHub Pages**（Settings → Pages → 选择 main 分支）即可获得在线链接。

## ✨ 功能特性

- 🎯 经典玩法：吃食物变长，撞墙或咬到自己游戏结束
- ⚡ 速度渐进：吃得越多，蛇跑得越快
- 🏆 最高分记录（本地保存，关掉浏览器也不丢）
- ⏸️ 暂停功能（空格键）
- 📱 支持手机：滑动屏幕即可操控
- 🖥️ 支持高分屏（Retina），画面清晰不模糊
- 🎨 深色主题 UI，蛇身渐变色 + 发光食物

## 🕹️ 操作方式

| 按键 | 功能 |
| --- | --- |
| `↑` `↓` `←` `→` 或 `W` `A` `S` `D` | 控制方向 |
| `空格` | 开始 / 暂停 / 继续 |
| 触摸滑动 | 手机上控制方向 |

## 🚀 本地运行

无需安装任何东西，直接双击 `index.html` 用浏览器打开即可。

或者启动一个本地服务器：

```bash
# Python
python -m http.server 8000

# Node.js
npx serve .
```

然后访问 `http://localhost:8000`

## 🛠️ 技术实现

- **Canvas 2D** 渲染游戏画面，`requestAnimationFrame` 驱动主循环
- **固定时间步进**（fixed timestep），移动速度不受帧率影响
- **输入缓冲队列**，快速连按也不会出现 180° 掉头误判
- `localStorage` 持久化最高分
